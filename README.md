## ✨ Features

- ✅ Smooth Framer Motion page animations and transitions
- ✅ Fully responsive — mobile, tablet, and desktop
- ✅ TypeScript for clean, maintainable, type-safe code
- ✅ SEO optimized with Next.js Metadata API
- ✅ Fast load times via Vercel edge deployment
- ✅ Animated hero section with typing effects
- ✅ Featured projects showcase with live links
- ✅ Contact section

## 📦 Getting Started

```bash
# Clone the repository
git clone https://github.com/NazneenRizvi/portfolio-site-v2.git

# Navigate into the project
cd portfolio-site-v2

# Checkout the correct branch
git checkout portfolio-v2

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
