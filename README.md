# 📖 About

This is my personal developer portfolio built to showcase my frontend development skills, featured projects, and professional services.

The portfolio is designed with a modern UI, smooth animations, responsive layouts, and an AI-powered Project Consultant chatbot to provide visitors with an interactive experience.

---

# ✨ Features

- ✅ Modern & Professional UI
- ✅ Fully Responsive (Mobile, Tablet & Desktop)
- ✅ Built with Next.js 16 App Router
- ✅ React + TypeScript
- ✅ Tailwind CSS
- ✅ Smooth Framer Motion Animations
- ✅ AI Project Consultant Chatbot
- ✅ Floating WhatsApp Contact Button
- ✅ Interactive Contact Form
- ✅ Featured Projects Showcase
- ✅ SEO Optimized (Metadata API, robots.txt & sitemap)
- ✅ Fast Performance
- ✅ Clean & Reusable Components
- ✅ Vercel Deployment

# 📦 Getting Started

```bash
# Clone the repository
git clone https://github.com/NazneenRizvi/portfolio-site-v2.git

# Navigate into the project
cd portfolio-site-v2

# Install dependencies
npm install

# Start development server
npm run dev
```

Open

```
http://localhost:3000
```

in your browser.
